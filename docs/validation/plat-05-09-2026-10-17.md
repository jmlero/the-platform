## PLAT-05 Kyverno

- Audit first: in `marina-system` every Pod and controller passed. Findings in
  third-party namespaces stay visible: Substrate's Postgres `tls-reloader`
  sidecar has no memory limit; `kint-worker` and the RustFS init Job have no app
  label.
- Enforce in `marina-system`, `marina-workers`, `platform-gateway`,
  `platform-ingress` and `platform-observability`. Server-side dry runs: a
  tag-only image, a missing memory limit and a missing label were denied; a
  compliant Pod passed.
- The NetworkPolicy rule denied a Pod in a scratch namespace without a policy
  and admitted it once one existed. During this work it also denied the first
  agentgateway Deployment, because its policies were not yet applied.
- Deck and Marina restarted and became Ready under enforcement. Kyverno uses
  about 123 MiB.

## PLAT-07 kgateway

- The `platform` Gateway and the Deck `TLSRoute` were accepted and programmed.
  The Envoy proxy passed the Kyverno policies with its pinned digest and limits.
- `https://localhost:8443` now goes through the Gateway: HTTP 200 with Deck's
  certificate verified against the installation CA. An unknown SNI name is
  refused. The cutover interrupted Deck for about 10 seconds.
- Deck's Service is ClusterIP; the old direct NodePort and host policy are
  removed from the local profile.

  settles the plan's open question.

## PLAT-08 MCP

- Jaeger's built-in MCP endpoint lists nine read-only trace tools. agentgateway
  federates it at `/mcp` and allows four. Through agentgateway: no key returned
  401; `tools/list` returned only the four; `get_services` answered; the unlisted
  `get_span_details` returned "Unknown tool" (HTTP 400).
- Marina's chat gateway has an MCP client and allow-list (`conversation.mcp`).
  Deterministic tests show: only allowed tools are offered, an allowed call
  reaches the server inside the turn and its result reaches the model, and an
  unlisted call stops the turn without reaching the server.
- Open: a live chat turn using an MCP tool, after the Marina image update.
