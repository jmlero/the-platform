# CHAT-03: Deck conversation invocation

- Date: 2026-09-23
- Environment: isolated Deck process and SQLite database on the local Mac;
  Chrome at `http://127.0.0.1:18080`. This was not a Kind or GCP deployment.
- Scope: Deck thread view and recording an explicit request to a configured
  conversation agent. No model or Marina conversation worker was run.

## Result

Deck now records the first configured agent for a thread and the exact human
message that invoked it. The channel invocation endpoint creates the message,
thread, selection, and event in one transaction. A caller request ID recovers
the same invocation after an uncertain response; changed content conflicts.
Only an installed logical agent advertising `conversation.invoke.{project_id}` can be
selected. The ordinary channel message endpoint keeps its save-only behavior.

The browser opens a focused thread with a stable URL, shows the selected agent
and linked tasks, and restores the thread on reload. The composer offers
configured agents and preserves the chosen agent for ordinary Send in that
thread. It labels a recorded request without suggesting that a worker replied.

## Verification

- Focused store and HTTP tests passed for selection, replay, changed-request
  conflict, CSRF, two operator sessions, export/import, and thread history.
- `npm test`, `npm run check`, and `npm run build` passed in `deck/web`.
- An isolated Deck process with authentication disabled and a disposable
  registered `conversation.invoke.prj_default` test agent was opened in Chrome. Selecting Codex
  and sending a message produced a thread URL and an “Agent requested” label.
  Reload preserved the thread and selection. A second ordinary Send recorded
  another request to the same agent without a mention. After the final
  project-scoped capability check, a second browser pass confirmed that the
  configured agent still appeared, a new invocation was recorded, and the
  thread survived reload. The preview process was stopped afterward.
- `make -C deck test check` passed. `make -C deck conformance` passed its
  real-process, two-session restart and export/import thread checks.

## Boundary

The regular local installation does not yet advertise a conversation-capable
Marina worker. These records remain pending intent until CHAT-04 adds governed
execution; CHAT-05–08 add clarification, task delegation, and result return.
No task was created or authorized in this proof.
