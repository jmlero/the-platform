The local rollback rehearsal is reproducible only within the saved private
baseline and the pinned image digests above: disable intake; record Deck task
and artifact hashes and Marina diagnostic identities; retain a copy of the
Marina data volume and old deployment/configuration; change only the Marina
image; wait for readiness and compare history; restore the old digest and
configuration; compare again. A release rollback procedure still needs the
kagent/Substrate data and schema migration path, with a trial that has active
kagent state. The existing local environment and spend boundary were respected;
GCP was not used.
