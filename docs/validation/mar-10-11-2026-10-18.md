## Found at the cutover and fixed

The sandbox tests could not show these; each fix has a test.

1. **Marina disabled its controllers.** The private chat profile still had
   `conversation.delegation`, which needs a capability the platform ledger does
   not offer: under decision 0033 a Turn only proposes a task and the client
   decides. Marina now rejects the retired setting with a clear error, and the
   private profile no longer has it.
2. **Deck got 403 on capabilities.** `Capabilities` is cluster-scoped, so the
   project RoleBinding cannot grant it. New ClusterRole `marina-capabilities`
   and Deck's ClusterRoleBinding `deck-marina-capabilities`.
3. **Deck showed Marina as disconnected.** It looked for Marina's last contact
   only through agents that own runs in the project. It now uses the project's
   last successful contact.
4. **A Run cancelled before it was claimed had no closing event.** The ledger
   now records `run.cancelled` with the cancel.

During the 403 period Deck counted 2,104 rejected contacts; the counter is
cumulative and has not grown since the fix.

## MAR-11: Marina from its Helm chart

The [chart](../../marina/deploy/helm/marina/README.md) installs Marina without
Deck: CRDs (generated from the OpenAPI schema), Deployment, Service, service
account, controller and client roles, worker namespace objects and network
policies. Engine RBAC and policies and trace export are options. Secrets and the
workflow stay outside the chart.

The local installation moved to it as the operator chose, instead of a second
cluster. The 20 objects the chart renders already existed and were marked for
Helm adoption; `helm upgrade --install --dry-run=server` and then the install
succeeded (release `marina`, revision 1). Marina restarted once on the same PVC
with image `sha256:0918a6caad16a1ac654af11d01f757e03d6018c4cdd008cf8a61845e7be0744c`.
The private Kustomization now uses the
[local-podman-helm](../../deploy/kubernetes/local-podman-helm/README.md) profile,
which keeps Deck, Secrets, ConfigMaps, the PVCs and the CRDs. The two engine
policies the chart folds into its own were deleted.
