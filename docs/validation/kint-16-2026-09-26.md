# KINT-16 permanent local engine and chat acceptance

- Date: 2026-09-25–26
- Environment: `kind-marina-local` on `podman-machine-default-root`, Deck at
  `https://localhost:8443`
- Result: permanent pinned kagent/Substrate installation and one bounded real
  chat reply accepted; repository work remained on the legacy runtime

## Installation and retained state

The pinned kagent `1.0.0-alpha1` / Substrate `0.2.0-beta4` stack was installed
with `--permanent` into installation-owned namespaces. The engine and Substrate
PostgreSQL and RustFS PVCs were bound; the controller, worker, gateway, database
and certificate Pods were Ready. Temporary image-preparation egress was removed.
The local Deck and Marina images were rebuilt from current source, loaded into
Kind and pinned by their imported containerd manifest digests:

| Image | Local manifest digest |
| --- | --- |
| Deck | `sha256:f17560eefd109c8de1c0b9f844e7e0034d108fd9da2c58e7e0e82a33b2cd8345` |
| Marina | `sha256:c2b57de840e61651702d549252ecfa8e7ba9637b444d5647406b41ca5772fb2a` |
| Conversation BYO actor in the task-owned registry | `sha256:67b0e55a1978e123796a91421ad6321081fb9f57730099b795a299fb27b42cb6` |

The private overlay selected the conversation profile at a five-minute,
10,000-token turn limit and fixed 30-minute, two-attempt repository delegation
ceiling. The Deck service identity gained the conversation feed and publication
capabilities. The Marina service account had `get`/`patch` only on the selected
attempt Secret. Existing Deck and Marina PVC identities were preserved and
copied before the image change; both SQLite copies passed `integrity_check`.
Marina's new-task intake remained disabled and no repository task was admitted.
The [local installation guide](../../deploy/kubernetes/local-podman-kagent/README.md)
records the setup and rotation procedure.

The first image apply used Podman's archive index digests as runtime image
references. Kind had cached the tagged manifests under different digests, so
both Deployments reported `ImagePullBackOff`. Re-pinning to the verified
containerd **manifest** digests made both Deployments Ready, and installation
preflight passed. Deck returned HTTP 200 at the required localhost URL.

reached `Ready=True`, and a Deck test-channel invocation created an ordered
human message in a durable thread.
