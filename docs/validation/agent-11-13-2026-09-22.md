## Supported limits

One operator, one active task and these two pinned workflows remain the boundary.
The analysis validator checks a fixed synthetic fixture, exact findings/quotes
and provenance; it is not a general semantic reviewer. Interrupted checkout,
model or tool operations can produce a blocker. The Python agent has no durable
step checkpoint or transparent replay of an interrupted model call. Failed or
cancelled work requires a newly authorized task. Automatic revision loops,
pause/resume, arbitrary tools, merge/deploy authority, HA and general agent
hosting remain future work. The local environment requires the Mac to remain on.
