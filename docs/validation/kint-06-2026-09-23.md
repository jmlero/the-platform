## Failure found and corrected during the pilot

The first native task, `tsk_976d6649807f9352ff18`, failed before a model call.
The router returned six HTTP 401 responses and its attempt Secret still held
the 64-byte placeholder. Marina called `InspectByKey` before installing the
credential, but this kagent recovery operation can create an instance and
deliver its message. A regression test now requires credential installation
before that call. Marina also collects terminal kagent artifacts before
cleanup, including a failed task with no output, so the original failed
instance was deleted without a repeated cleanup conflict. The failed task
created no branch or PR. The retry used a fresh attempt-exclusive template
and Secret, as required by the immutable engine credential contract.
