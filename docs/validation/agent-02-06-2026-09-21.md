## Deterministic verification and limits

`make check` passed all installation, CLI, Deck and Marina checks, including
20 frontend tests and zero Svelte errors/warnings. `make conformance` passed
CLI and Marina tests against real Deck processes. The analysis scenarios reopen
Marina's journal between every workflow step and cover successful recovery,
missing findings, wrong input digests, missing/corrupt worker output, corrupted
validation evidence before completion, changed profiles and incorrect grants.
Repository scenarios still reject failed verification, changed heads, closed PRs,
missing CI and missing authority. Gateway tests check denied source access and
tools, durable accounting, exact input binding and idempotent result upload.
The real installed LangChain integration test also passed against a local fake
Responses endpoint; that test is distinct from the real-model runs above.

This is one fixed synthetic analysis fixture with no external tools. The
validator checks expected findings, source IDs, verbatim causal quotes and
digests; it does **not** certify the free-form remediation advice. For example,
the model suggested releasing an unknown usage reservation, which the fixture
does not authorize or justify. No such action was performed. Broader semantic
review and useful live-production diagnostics require separate work.

Active-worker restart/cancellation/provider-failure scenarios for this second
harness were not newly exercised in this tranche; shared deterministic checks and
prior repository acceptance remain separate evidence. The later
[AGENT-11–13 report](agent-11-13-2026-09-22.md) records the combined failure
matrix, public invocation, selected context/tool behavior, result inspection, and
repeatable installation. Neither report claims general agent hosting or
representative economic value.
