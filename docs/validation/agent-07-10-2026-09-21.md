```sh
make check

```

Deck frontend tests and Svelte checking. Conformance builds real Deck processes
with isolated SQLite stores and scoped service credentials; it also exercises
the CLI's authenticated operator session. New profile scenarios cover repository

context, missing/mismatched/corrupted outputs, stale profiles and wrong authority.

actual Go tool gateway against real Deck authority. Git, Kubernetes runtime and
model output are deterministic test boundaries in this suite; these checks are
not live model, Git-provider or new Kubernetes workload acceptance.

process, using a trusted temporary CA, synthetic operator/service credentials,
secure session cookies and CSRF. Capability/profile discovery, invocation,
identical replay, task inspection and recording a cancel command passed.
[Redacted client observations](agent-07-10-client-2026-09-21.json) record the task
and run IDs. No worker executed; cancellation termination is covered by the
workflow tests, not inferred from command submission. The temporary server and

## Remaining release boundary

The new Deck/Marina API, gateway and v2 harness code were not deployed together
for a live model run in this tranche. Existing installations need the new Deck
migration/binary, Marina binary, publisher capability and a newly built,
digest-pinned v2 analysis image before exposing the new capabilities. An old v1
image cannot advertise tools/context merely because Deck was upgraded.

AGENT-11 retains the complete shared failure/recovery matrix; AGENT-12 retains
repeatable installation/upgrade packaging; AGENT-13 retains combined live MVP
acceptance with API invocations and actual Jobs for both workloads. The earlier
[PoC proof](agent-02-06-2026-09-21.md) remains the live-model evidence for the
fixture-only harness. No broader acceptance is inferred from these tests.
