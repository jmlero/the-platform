# CHAT-04: bounded conversational execution

- Status: deterministic implementation complete; local model and engine acceptance pending

## Implemented boundary

Marina can opt into a pinned `conversation` profile. It registers its stable
agent with the project-scoped `conversation.invoke.{project_id}` capability,
polls Deck's ordered invocation feed, records invoked turns and event cursors in
its own SQLite journal, freezes at most 20 thread messages in a digest-addressed
input, and dispatches through the existing kagent adapter. A turn has a deadline,
one model call, a token reservation, a fixed prepared revision, a scoped gateway
credential and no repository, shell, tool, task, or source-write route. The BYO
actor accepts only the frozen input and returns a bounded, identity-bound result
artifact. Marina validates that artifact, observes cleanup, and retains its
digest in the journal. Cancellation collects and cleans up after observed
termination. Unknown model responses retain their reservation.

The profile names one attempt-exclusive AgentTemplate and Secret. Marina refuses
to assign a template already recorded for another turn. A new prepared template
and profile selection are required for the next turn. The model endpoint, price
configuration and policy version are bound at gateway admission; changing them
stops an active turn rather than silently changing its authority.

The result currently remains in Marina's journal and artifact store. Deck thread
publication, clarification, task delegation and feedback belong to CHAT-05–08.
This profile does not make the full conversation-to-result browser flow available.
