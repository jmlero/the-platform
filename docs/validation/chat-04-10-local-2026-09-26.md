- Date: 2026-09-26
- Environment: `kind-marina-local` on `podman-machine-default-root`, Deck at
  `https://localhost:8443`, pinned kagent/Substrate, read-only conversation BYO
  actor and governed model gateway.
- Result: two new browser-invoked draft requests blocked after model accounting.
  No draft task was created. This does not satisfy CHAT-04–10 acceptance.

The browser invoked a concrete Backlog draft request in message
`msg_9500b320fa253cf51b3b`, then a shorter request in
`msg_bd9f60c6fdab08cf5968`. Both appeared in their Deck threads and later
showed `Conversation agent failed or was cancelled`. Marina's journal recorded
the turns as blocked, each with `model_call_status=completed` and respectively
429 and 538 used tokens. The kagent controller accepted the instance and
message and deleted each instance after its terminal result. Neither request
published a task. This locates the observed failure after the model gateway
accounted for usage, without proving which actor processing step failed.

The actor previously reported only a failed A2A state. Its source now logs a
bounded error category on failure without logging model text or credentials.
`go test ./internal/conversationbyo` passed and a diagnostic ARM64 image was
placed in the dedicated local registry and pinned to the conversation Harness.
The next one-use template, `kint16-chat-13`, could not become Ready: Substrate
repeatedly reported `ResourceExhausted: no free workers available` while
resuming golden actors for it and older templates. Restarting the dedicated
worker and temporarily increasing it from one to two replicas did not resolve
the condition; the deployment was returned to one replica. The private Marina
profile was not changed by the failed helper and still selects the now-used
`kint16-chat-12` revision. No diagnostic turn ran on the new actor image.

Before more browser acceptance, recover the golden-snapshot capacity without
discarding historical actor state, prepare a fresh one-use template and exact
Secret grant, then repeat a model reply, draft delegation, typed question,
result publication, follow-up, restart and lost-response cases. Repository
intake remained disabled during this probe.
