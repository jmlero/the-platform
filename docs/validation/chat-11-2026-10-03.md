## Frozen input and read boundary

Deck now captures the active selected project-source revisions and safe repository
binding atomically when the operator invokes the chat agent. The additive
`conversation.context.read` capability exposes only that invocation's saved
selection through the public HTTP/JSON contract, scoped to its project. New
source revisions do not change existing invocations. Explicit revocation remains
observable. Older invocations without a snapshot return 404 rather than
silently selecting current sources.

Marina captures the repository's exact commit and regular-file index before
dispatch, then persists the tree and frozen conversation input as artifacts.
Recovery reuses those artifacts. The configured Git adapter admits only the
installed repository origin and private credential reference; credentials never
enter the actor's input. Selected sources retain their identity, digest and trust.
Repository text and tool results supply data and cannot expand authority.

The gateway fixes the thread, installed instructions, model and two available
tools: `list_repository_files` and `read_repository_file`. The tools read the saved
revision only. There is no write, shell, commit, merge or deployment tool. Model
continuations share the original turn's deadline and token reservation, with at
most four model rounds, four tool calls per round, 16 KiB/200 lines per file window
and 64 KiB of aggregate tool-result bytes. Authority and selected-source validity
are checked before further model spend and reads.
