## Cutover (KINT-11)

The installation's workflow profile selects `repository_engine` (kagent,
harness `kint-codex`) and `fast_forward` delivery. Marina's journal holds 28
implementation attempts on the Kubernetes Job runtime. All of them are finished;
the last started on 2026-09-27 at 15:40 and ended at 15:42. Every repository
implementation attempt after it ran on native Codex: 29 by 06:00 on 28 September,
plus the CHAT-10 task below. At the end of the run no execution was unfinished.

An attempt's engine is part of its durable specification, and dispatch and
recovery read it from there. `TestActiveAttemptStaysOnItsEngineWhenTheProfileChanges`
in [`marina/internal/flow/template_test.go`](../../marina/internal/flow/template_test.go)
starts an attempt on one engine and then changes the profile in each direction.
The attempt stays on its engine, with no new start and no new template. The test
fails if dispatch follows the current profile instead.

Each attempt gets its own engine template, which Marina removes afterwards
([decision 0024](../decisions/0024-per-attempt-engine-templates.md)).
