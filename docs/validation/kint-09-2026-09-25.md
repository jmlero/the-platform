# KINT-09 local cancellation follow-up, 25 September 2026

**Status: KINT-09 remains Open.** This was an isolated trial on local Podman/Kind
`kind-marina-local`. Deck and Marina remained on their existing images and stores;
Marina intake stayed disabled. The trial used a fixed question actor with no
working inference endpoint, repository authority, or Git publication. It proves
one waiting-for-input cancellation case, not the two-workload failure matrix.
The [23–24 September partial report](kint-09-10-2026-09-24.md) records the
earlier live cases and remaining gates.

## Result

The pinned trial kagent and Substrate installation prepared a fresh isolated
Harness/AgentTemplate pair, `kint09-question-harness` and
`kint09-question-fixed`, at revision
`5cb1eed24b9b6055c9accc2834b2c302872e3eebf7a31a5708aa6ecca075ba61`.
Its local worker image digest was
`sha256:611e2693ca40493338b3369061981f523f4c63bd390f9e550d81f35d26512aae`.
The temporary `kint-preparation-downloads` policy was opened only to fetch that
image and produce the golden snapshot, then deleted before the test.

`TestLiveCancelWhileWaitingForInput` in
[`marina/internal/kagent/live_test.go`](../../marina/internal/kagent/live_test.go)
ran through a real loopback port-forward to the trial engine. It observed one
fixed input-required question and exactly one `SendMessage`. Marina cancelled
the original task, observed the engine instance's deletion, then rejected an
answer to the cancelled question without another send. The instance was
`01a0d70c-06e8-70f2-9589-4eed14fa7bd9`; the task was
`01a0d70c-06fa-7b92-a3dc-16bd7c90cfcc`. The opt-in live test passed in
0.35 seconds. Its cleanup reads the durable attempt record even if `Start`
fails after creating an instance.

The live test is gated by `KINT09_CANCEL_QUESTION=1` and takes the loopback
`KINT03_ENDPOINT`, `KINT09_QUESTION_HARNESS`, `KINT09_QUESTION_TEMPLATE` and
exact `KINT09_QUESTION_REVISION` from the isolated prepared fixture. The fixture
must ask question `kint08-diagnostic-scope` without inference authority. The
result above used the named pair and revision recorded in this report.

The first trial image had a Go test timeout embedded in its golden snapshot.
Restoring that snapshot hours later expired the timer before the actor could
serve the question; `Start` returned an uncertain delivery error. We deleted
that exact failed synthetic instance and actor after its worker was replaced.
The corrected image disables the fixture's internal test timer while the live
test retains its outer three-minute timeout. This was a fixture failure before
user work, so it is not counted as a cancellation pass.

## Remaining matrix

The [mandatory matrix](https://github.com/jmlero/the-platform/blob/b7ccd54cdf79f3f669d23c75eb5c9840f43de953/docs/plans/kagent-integration.md#mandatory-failure-matrix) still
requires both real workload paths through Deck and Marina. In particular, the
current evidence does not cover active model and tool call cancellation; live
lease/context revocation and budget exhaustion; engine, worker and Marina
restarts during work; event reordering; bypass attempts; verifier, PR and CI
staleness; lost source-publication responses; or artifact failure. Earlier
synthetic response-loss, template revision and idle restart cases remain partial
evidence. No model spend or repository mutation was performed in this follow-up.
KINT-11 cutover must remain gated on the full KINT-09 and KINT-10 results.

## Checks and teardown

- `make -C marina check` passed before and after the trial;
  `make check-installation` passed 19 tests before and after the trial.
- The opt-in live cancellation test passed against real kagent/Substrate. The
  ordinary `go test ./internal/kagent -run '^TestLiveCancelWhileWaitingForInput$'
  passed with the live gate skipped.
- The trial engine reported no remaining instances before teardown. Its worker
  pool, three trial namespaces, labeled cluster resources, and three generated
  trial trust bundles were removed. Only the pre-existing Kubernetes API-serving
  trust bundle remained. The task-owned local registry was removed.
- The Kind API server manifest matched its saved pretrial copy byte for byte;
  `/readyz` returned `ok`. Deck and Marina deployments rolled out with their
  original UIDs, image digests, and Marina `--intake-enabled=false` argument.
  Both original PVC UIDs were unchanged. Deck returned HTTP 200 at
  `https://localhost:8443` after teardown.
