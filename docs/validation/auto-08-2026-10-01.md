## Review and publication

Native Codex produces an immutable candidate. A separate text-only review uses
the existing BYO actor, a fresh attempt/template/credential and a different
configured model. Its input contains the frozen task, acceptance criteria,
context, trusted check commands, complete candidate and original files at its
exact base, and any repair history and diagnosis. The 256 KiB input limit blocks
oversized input without truncating files. Pinned Git tree/blob reads reject
symlinks, submodules, incomplete trees and unavailable source.

The gateway fixes the review model, installed instructions and exact input.
It rejects Git access, tools, session continuation, arbitrary instructions and
changed input. Every verdict includes acceptance, scope, tests, repair approach
and defects, with bounded reasons and file/line citations. The trusted prompt
requires rejection of weakened, removed or skipped tests and insufficient
acceptance coverage. These prompt rules and synthetic rejected verdicts are
tested; live detection by the selected model is still an acceptance gate.

Only a valid passing independent verdict permits branch creation and publication
of the saved candidate. Its digest includes the base, paths, bytes, modes and
delete operations. Changing the producer artifact, candidate base or reviewer
identity denies publication. Existing clean verification and exact-commit CI
remain required after review.

Stored semantic-review evidence joins the patch, base, resulting commit,
reviewer attempt, configured model and frozen profile. A rejected review has no
resulting commit and counts once, regardless of failed check count. Diagnosis
precedes repair; disputed or out-of-scope findings escalate. Missing or malformed
verdicts block without incrementing implementation failures. Earlier observations
remain history; completion selects the latest commit's review and clean checks.

## Budget and recovery checks

Review uses the original execution's token, cost, time and runtime-start budgets.
Deck discovery and invocation accept the explicit review minimum and retain old
two-start profile semantics. Undersized invocation or delegation budgets are
rejected without enlargement. Current limits are in the
[profile contract](../../marina/docs/workloads/profiles-v1.md#immutable-selection-and-authorization).

The gateway retains known review responses and accounting before delivery.
Restart replays the same response with one upstream call and no additional spend.
Unknown usage keeps its reservation and prevents another call. Lost runtime
start, commit and evidence responses recover using the original identities.

Deterministic flow checks reopen SQLite between transitions and exercise:

| Case | Runtime starts | Commits | Outcome |
| --- | ---: | ---: | --- |
| Initial passing review | 3 | 1 | Clean verification and CI permit one landing |
| One rejected review, then repair | 6 | 1 | Rejected patch never commits; repaired patch is reviewed and lands once |
| Three rejected reviews | 8 | 0 | Blocked at three failures, even with a larger task budget |
| Failed clean verification or required CI, then repair | 7 | 2 | Fresh review and verification for the repaired commit |
| Three failed clean verifications | 11 | 3 | Blocked; nothing lands |
| Missing verdict checks | 2 | 0 | Infrastructure blocker; no implementation failure counted |
| Disputed review finding | 3 | 0 | Diagnosis retained; escalated before another implementation |
| Uncertain producer model usage | 1 | 0 | Reservation retained; no review or publication |

`internal/flow/review_test.go` covers the precommit gate, rejection feedback,
exact candidate binding, invalid verdicts, restart/lost-response recovery, failure
limits, disputes and oversized input. Work-result and actor tests validate the
structured contract and preserved test-weakening findings. Gateway tests use real
TLS requests to a deterministic Responses endpoint to verify read-only authority,
the independent model, original accounting and response replay across restart.
Git adapter tests exercise pinned tree/blob reads and failed source admission.
