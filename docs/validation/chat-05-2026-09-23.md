## Implemented boundary

Deck stores each typed engine question under the exact invoked message, selected
agent and thread. The question is one canonical agent message. An operator answer
is one canonical human reply to that question. The question request and answer
request replay to the same IDs; changed content and second answers conflict.
Questions and answers survive restart and project export/import. No task is
created or authorized by an answer.

Marina replays the question to Deck while the engine waits, verifies the returned
project/channel/thread/invocation/agent/question IDs, and sends an answered value
only to the matching kagent question on the same attempt. The kagent adapter's
durable answer-send record handles an unknown response without a second send.
The pending question remains bounded by the conversation turn deadline.
